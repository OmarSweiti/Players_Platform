# Requirements traceability

Every requirement ID in the four frozen documents, with the microsteps that deliver it and how many of
them are done. The table is **generated** from the phase files' Requirements lines by `just plan`; the
plan check fails when an ID is owned by no microstep and not deliberately deferred (see the master
plan's [deferred requirements](../implementation/00-master-plan.md#deferred-requirements)), when a
microstep cites an ID that does not exist, or when the table is stale.

A requirement owned by several microsteps is delivered in parts — for example, a cross-cutting
non-functional requirement built in Phase 0 and verified at a later gate. "Done" counts merged microsteps,
not verified releases; release acceptance is each phase's exit gate.

The four source documents and their checksums: [`../requirements/README.md`](../requirements/README.md).
